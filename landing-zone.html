HNE AI Platform Landing Zone

A practical foundation for building AI projects safely and moving successful proofs of concept into production. One platform administrator maintains the baseline. Product teams build within it.

Workshop outcome: agree the target platform shape, the provisioning order, the minimum resource checklist, and the ownership model. This is a landing-zone blueprint, not a production deployment in two days.

Target operating model

One administrator, clear guardrails

Platform administrator

Maintains the baseline

Subscriptions, networking, private endpoints, policies, RBAC, diagnostic settings, budgets, and standard Foundry project templates.

Product teams

Build inside the baseline

Agents, knowledge sources, evaluations, prompts, applications, and use-case-specific MCP tools, using approved resources and identities.

Security and governance

Approve and review

Model residency, data access, risk level, agent publishing, exceptions, and evidence that the project meets policy.

Finance and operations

See and control usage

Budgets, cost-centre tags, token usage, API traffic, latency, failures, and alerts for unexpected spend.

Setup roadmap

How long the foundation takes

1. Decide

1 to 2 weeks

Confirm subscriptions, environment boundaries, ownership, network baseline, allowed regions, and cost tags.

2. Build baseline

2 to 4 weeks

Deploy hub/spoke networking, private DNS, Foundry resources, Search, Storage, Key Vault, RBAC, policies, and telemetry.

3. Enable builders

1 to 2 weeks

Publish the project template, onboarding checklist, sample agent, knowledge-source pattern, and CI/CD path.

4. Operate

Ongoing

One administrator maintains the platform. Product teams onboard use cases through the standard intake and checklist.

These are planning ranges, not commitments. Network connectivity, security review, quota availability, and procurement decisions can change the timeline.

Production readiness

Minimum checklist before a POC moves forward

  • Dev, test, and prod boundary agreed
  • Resource groups and cost tags defined
  • Foundry account and project created
  • Approved model deployments available
  • Managed identities and RBAC assigned
  • Azure Policy baseline applied
  • Private endpoint and DNS decision made
  • Search, Storage, and Key Vault connected
  • Diagnostic settings and App Insights enabled
  • Budgets and cost alerts created
  • Agent and tool permissions reviewed
  • Evaluation and citation tests passing
