Rebuilding HNE's knowledge chatbot on Microsoft Foundry

Taking Hamburger Energienetze's existing Azure AI Search index and turning it into a governed, cited, agentic RAG experience — running end-to-end in HNE's own Azure subscription.

Microsoft Foundry Agent Service Azure AI Search · Foundry IQ Runs in HNE's own subscription Internal workshop material
Success criteria

Two headline deliverables — everything else supports these

1

A working RAG retrieval flow

HNE's existing Azure AI Search index registered as a Foundry Knowledge Source, queried with hybrid search, answering real questions with citations — not a synthetic demo dataset.

2

A live Hosted Agent demo

That same knowledge source wired into a Hosted Agent (Preview) a real client can talk to directly through a minimal chat web app, not just a notebook script.
