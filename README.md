# HNE × Microsoft Foundry — Hackathon Showcase

A single static page summarizing the HNE × Microsoft Foundry hackathon (17–18
August): the use case, architecture, schedule, module structure, and roadmap.

This is a **presentation companion**, not the workshop's source code — it
contains no credentials, no client-internal specifics beyond what's shown on
[hamburgernetz.de](https://www.hamburger-energienetze.de), and no confidential
material. The actual labs, scripts, and infrastructure code live in a separate
private repository.

## Access

The page has a simple password gate. It's a client-side speed bump for an
internal demo, not real access control — GitHub Pages is a static host and
can't do server-side authentication. Nothing sensitive is published here.
